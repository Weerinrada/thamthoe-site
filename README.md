# ธรรมเถอะ

แอปสวดมนต์และภาวนาแบบไฟล์เดียว ใช้งานได้บนมือถือ ติดตั้งเป็น PWA ได้ และเปิดอ่านได้แม้ไม่มีอินเทอร์เน็ต

## ฟีเจอร์

แอปแบ่งเป็น 6 หน้าหลัก (แถบด้านล่าง):

- **หน้าแรก** — ภาพรวม ความสม่ำเสมอ (streak, จุด 7 วัน, milestone ล่าสุด) และทางเข้าสู่การสวด/ภาวนา
- **บทสวด** — คลังบทสวดภาษาบาลี พร้อมคำแปลและคำอธิบาย ค้นหาและกรองตามหมวดได้
- **ชุดของฉัน** — จัดชุดบทสวดที่ใช้เป็นประจำ เพิ่ม/ลบ/เลือกชุดที่กำลังใช้
- **ภาวนา** — ตั้งเวลา 1–240 นาที (มีปุ่มตั้งเวลาเร็ว 5/10/15/30/60/90 นาที) โหมดนั่งสมาธิ/กสิณ/เดินจงกรม มีเสียงระฆังเมื่อครบเวลา `หยุด` เป็นการพักจับเวลา ส่วน `จบการภาวนา` จะเก็บเวลาที่ผ่านจริง ขณะจับเวลาจะใช้ Screen Wake Lock ช่วยไม่ให้จอดับ (ต้องเสิร์ฟผ่าน HTTPS และเบราว์เซอร์ต้องรองรับ)
- **บันทึก** — เขียนบันทึกสภาวธรรม เพิ่ม/ลบ และดูย้อนหลัง
- **โปรไฟล์** — สถิติการฝึก (นาทีสวดมนต์รวม รวมบทเมตตา และนาทีสมาธิ) ปรับขนาดตัวอักษร เลือกโหมดการอ่าน (เลื่อนอ่านทั้งบท / อ่านทีละหน้า) และระบุชื่อที่ใช้ในบทสวด

เมื่อสวดครบหนึ่งชุด sẽมีปุ่มไปนั่งสมาธิ และเมื่อจบการภาวนาจะมีปุ่มไปสวดเมตตาจากชุดที่กำลังใช้ (ถ้าไม่มีบทเมตตาในชุดจะเปิดบทเมตตาจากคลังแทน) หนึ่งครั้งฝึกที่จบจะถูกเก็บเป็น `thamtoe_sessions` แยกตามประเภท `chant` / `meditation` เท่านั้น (บทเมตตาก็นับเป็น `chant`) เวลาสวดมนต์วัดจาก timestamp ตอนเริ่มบทแรกจนถึงบทสุดท้ายของแต่ละชุด แล้วรวมเข้าด้วยกัน ข้อมูลเก่าที่เคยเก็บเป็น `metta` จะถูกรวมเข้ากับยอดสวดมนต์โดยอัตโนมัติ เพื่อใช้คำนวณ streak และ milestone (7 วัน, 30 วัน, 100 ครั้งฝึก)

รองรับ light/dark ตามการตั้งค่าของเครื่อง ปรับให้พอดีกับ safe area ของ iPhone และโหลดฟอนต์ Anuphan/Sarabun จาก Google Fonts

## โครงสร้างไฟล์

| ไฟล์                                  | รายละเอียด                                                                                       |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `index.html`                         | แอปทั้งหมด: React + Tailwind + โค้ดแอป รวมอยู่ในไฟล์เดียว (bundle ที่ build ไว้แล้ว)                       |
| `sw.js`                              | Service worker สำหรับเก็บแอปและฟอนต์ไว้ในเครื่องแบบออฟไลน์                                             |
| `manifest.webmanifest`               | ตั้งค่า PWA (ชื่อ, ไอคอน, `standalone`)                                                              |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนสำหรับ PWA และ iOS                                                                          |
| `scripts/check-index-bundle.mjs`     | ทดสอบว่า inline script ทุกตัวใน `index.html` parse ได้ มี mount ไปยัง `#root` และไม่มีฟีเจอร์จำลองที่ถอดออก |
| `scripts/test-wake-lock.mjs`         | ทดสอบ helper ของ Screen Wake Lock แบบแยกหน่วย                                                    |
| `scripts/test-practice-seams.mjs`    | ทดสอบ payload ของครั้งฝึก เวลาสวดมนต์จาก timestamp และเป้าหมายการส่งต่อไปสวดเมตตา                      |

## รันในเครื่อง

เปิดไฟล์โดยตรงก็ได้ แต่เพื่อให้ service worker และ PWA ทำงาน ควรเสิร์ฟผ่าน HTTP:

```bash
python3 -m http.server 8080
```

แล้วเปิด `http://localhost:8080` (ต้องเป็น `http://` หรือ `https://` ถึงจะมี service worker)

## ข้อมูลและการจัดเก็บ

แอปเรียก `POST actions` เพื่อบันทึก/อ่านข้อมูล (collections: `thamtoe_custom_set`, `thamtoe_journal`, `thamtoe_reading_prefs`, `thamtoe_sessions`) หากเชื่อมต่อไม่ได้จะ fallback ไปเก็บใน `localStorage` ที่คีย์ `thamtoe_records_v1` แทน และแจ้งว่าเป็นโหมดออฟไลน์ชั่วคราว

## การพัฒนา

```bash
npm install
npm test        # ตรวจ bundle, wake lock และ practice seams
```

มี Husky pre-commit hook ที่รัน `lint-staged` (Prettier เฉพาะไฟล์ที่ staged) แล้วตามด้วย `npm test`

> **ข้อควรระวัง:** `index.html` คือ bundle ที่ minify ไว้แล้ว ห้ามให้ Prettier/jsdelivr ฟอร์แมตไฟล์นี้ เพราะจะทำให้สคริปต์เสียและหน้าเว็บว่างเปล่า ไฟล์นี้และ `dhamma-thoe-*.html` ถูกระบุไว้ใน `.prettierignore` แล้ว

## การ deploy

เป็น static site: อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไปยังโฮสต์ที่รองรับ HTTPS (เช่น GitHub Pages) ไม่มี build step

เมื่ออัปเดต `index.html` ให้เพิ่มเลข `VERSION` ใน `sw.js` ด้วย เพื่อให้เครื่องล้างแคชเก่าแล้วโหลดไฟล์ใหม่

## วิธีใช้งานสำหรับผู้ใช้ฟรี (User Guide)

แอป **"ธรรมเถอะ (Thamtoe)"** เป็นเครื่องมือสวดมนต์และภาวนาแบบ **ไฟล์เดียว** ใช้งานได้ **ฟรี** สำหรับทุกคน ตั้งใจทำขึ้นเพื่อ:

- ✅ ผู้ที่อยากสวดมนต์แต่ **ไม่อยากพกหนังสือสวดมนต์** → เปิดอ่านได้จากมือถือ / แท็บเล็ตทันที
- ✅ ผู้ที่อยากฝึกสมาธิแต่ **ไม่อยากเปิดแอปตั้งเวลาเตือนแยก** → แอปรวมทั้งสวดและเตือนทำสมาธิไว้ในที่เดียวแล้ว

### คุณสมบัติหลักที่ใช้งานได้ทันที

| ฟีเจอร์ | รายละเอียด |
|--------|------------|
| **PWA (ติดตั้งแอป)** | ติดตั้งบนเบราว์เซอร์ Chrome/Firefox/Safari/Edge ได้ทันที ไม่ต้องเสิร์ฟผ่าน HTTP |
| **อ่านออฟไลน์** | กด "ดาวน์โหลดออฟไลน์" บนแต่ละบทสวดแล้วอ่านได้โดยไม่ต้องต่ออินเทอร์เน็ต |
| **เตือนทำสมาธิในตัว** | ตั้งเวลา 1–240 นาที มีปุ่มเร็ว 5 / 10 / 15 / 30 / 60 / 90 นาที |
| **สำรองข้อมูล** | "ส่งออกเป็นไฟล์" / "นำเข้าข้อมูล" เพื่อย้ายจาก iPhone → iPad หรือเครื่องอื่น โดยไม่สูญเสียข้อมูล |
| **ใช้งานฟรี** | ไม่มีค่าใช้จ่าย ไม่มีโฆษณา ใช้งานได้ตลอดไป |

### ขั้นตอนสำหรับผู้ใช้

1. **เปิดลิงก์เว็บ** (เช่น `https://weerinrada.github.io/thamthoe-site/`)
2. **ติดตั้งเป็น PWA** (เพื่อให้ใช้งานออฟไลน์ได้):  
   - Chrome/Firefox/Safari/Edge — เปิดเว็บแล้วกด "ติดตั้งแอป (PWA)"  
   - iOS — กด "Add to Home Screen" จากเมนูแชร์
3. **ดาวน์โหลดบทสวดออฟไลน์**: ในหน้า "ชุดสวดสำเร็จรูป" หรือ "บทสวดทั้งหมด" กด **"ดาวน์โหลดออฟไลน์"** บนบทที่ต้องการ
4. **ตั้งเวลาเตือนทำสมาธิ**: ไปที่หน้า "ภาวนา" แล้วเลือกเวลา (1–240 นาที)
5. **สำรองข้อมูล**: กด "ส่งออกเป็นไฟล์" เพื่อดาวน์โหลด JSON สำรอง ไปนำเข้าที่เครื่องอื่นได้

## การฝาก / ส่งต่อให้เพื่องทดลอง (Deploy & Share)

### แนวทางปัจจุบัน (ตัวเลือก B — GitHub Actions)
เมื่อ push โค้ดขึ้น `main` บน repository `Weerinrada/thamthoe-site` GitHub Actions จะรันทดสอบและ deploy ไปยัง GitHub Pages โดยอัตโนมัติ เว็บจะออนไลน์ที่:

```
https://weerinrada.github.io/thamthoe-site/
```

ให้ส่งลิงก์นี้แก่เพื่อนทดลองใช้งานได้เลย

### วิธีส่งต่อให้เพื่องทดลองเฉพาะ (Staging / preview)
หากต้องการให้เพื่อนทดลองฟีเจอร์ใหม่ก่อนปล่อยจริง:

1. สร้าง branch ใหม่ เช่น `fix/remove-chant-filters` หรือ `feature/preview-home`
2. Push branch นั้นขึ้น GitHub
3. เปิด PR แล้วแชร์ลิงก์ให้เพื่อนทดลองใน PR (หรือตั้ง GitHub Pages ให้ deploy preview)
4. เมื่อทดสอบแล้ว merge เข้า `main` จะอัปเดตเว็บจริงอัตโนมัติ

> **ข้อควรระวัง:** `index.html` คือ bundle ที่ minify ไว้แล้ว ห้ามให้ Prettier/jsdelivr ฟอร์แมตไฟล์นี้ เพราะจะทำให้สคริปต์เสียและหน้าเว็บว่างเปล่า ไฟล์นี้และ `dhamma-thoe-*.html` ถูกระบุไว้ใน `.prettierignore` แล้ว
